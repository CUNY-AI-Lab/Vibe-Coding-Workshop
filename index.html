Command Line Basics

Let's get comfortable with the terminal

Opening Your Terminal

Mac:

  1. Press Cmd + Space
  2. Type "Terminal"
  3. Press Return

Windows:

  1. Press Windows key
  2. Type "PowerShell"
  3. Press Enter

Essential Commands

ls List files & folders in current directory
mkdir <name> Create a new folder
cd <name> Move into a specific folder
pwd Show your current location
cd .. Move up one level to parent directory

Command Line Syntax

command --option <placeholder-argument>

Example: mkdir my-project

Installing Gemini CLI

Windows (PowerShell)

  1. Install Node.js: nodejs.org/en/download
  2. Install Gemini CLI: 
    npm install -g @google/gemini-cli

macOS (Terminal)

  1. Install Homebrew: brew.sh
  2. Install Gemini CLI: 
    brew install gemini-cli
